How it works

  • Use Auto for responsive calendar/agenda switching, or choose Calendar or Agenda manually.
  • Calendar days show only entry count and total hours; click a day to see details.
  • Click a day to add several check in, check out, project, and description entries.
  • Open the project list to delete a project and all of its related entries after confirming.
  • Duration is calculated automatically in hours. Overnight work is supported.
  • Use Report to see project totals for a period and export the detailed CSV.
  • Data is stored in the data file you open or create. The desktop app reopens your last selected file automatically.
